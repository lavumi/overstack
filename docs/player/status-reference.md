# Status Reference

현재 Overstack에서 쓰는 상태이상과 버프 목록입니다.

## Debuff

### Burn

- 지속 피해
- `Cinder Scholar` 같은 trait와 시너지

### Freeze

- 게이지 진행 속도 감소
- `Frozen Momentum`, `Shatterpoint`와 시너지

### Shock

- 후속 반응 트리거용 상태
- `Overcharge`와 시너지

### Break

- 방어 상호작용 상태
- 물리 피해 계산과 연결

### Bleed

- 지속 피해

### Stun

- 게이지 진행을 막는 제어 상태

## Buff

### Might

- 공격 강화 버프

### Haste

- 게이지 진행 속도 강화 버프
- 기본 speed 값 위에 배율로 적용됨

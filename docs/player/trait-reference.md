# Trait Reference

현재 selectable trait와 주요 enemy trait 목록입니다.

## Player selectable traits

### Cinder Scholar

- id: `cinder_scholar`
- cost: `4`
- 설명: 플레이어가 거는 Burn을 더 강하게 만듭니다.

### Frozen Momentum

- id: `frozen_momentum`
- cost: `5`
- 설명: Freeze를 걸면 Break stack을 추가합니다.

### Overcharge

- id: `overcharge`
- cost: `6`
- 설명: Shock를 걸면 bonus pure damage를 줍니다.

### Shatterpoint

- id: `shatterpoint`
- cost: `7`
- 설명: Break가 걸릴 때 Freeze 상태 대상에게 Stun을 시도합니다.

### Ruthless

- id: `ruthless`
- cost: `8`
- 설명: 상태이상이 2개 이상 걸린 대상에게 추가 피해를 줍니다.

## Enemy trait

### Iron Shell

- id: `enemy_iron_shell`
- cost: `9`
- 설명: 적이 전투 시작 시 저항 보정을 얻습니다.

## 규칙 메모

- 시작 빌드에서는 현재 player selectable trait 중 정확히 1개만 선택합니다.
- trait cost는 시작 예산에 포함됩니다.

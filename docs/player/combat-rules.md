# Combat Rules

이 문서는 전투가 실제로 어떻게 진행되는지 설명합니다.

## 기본 전투 흐름

전투는 게이지 기반으로 진행됩니다.

1. 전투 시작
2. 각 유닛의 `action_gauge` 증가
3. `action_gauge >= 100`이 된 유닛이 행동
4. 행동 결과로 피해와 상태이상 적용
5. 한쪽이 모두 쓰러질 때까지 반복

## Speed와 게이지

각 유닛의 게이지는 아래 개념으로 증가합니다.

`action_gauge += speed * dt * multiplier`

- `speed`는 절대값 스탯
- `dt`는 시뮬레이션 시간
- `multiplier`는 상태이상으로 바뀌는 추가 배율

## 상태이상이 속도에 미치는 영향

현재 게이지 속도 관련 상태:

- `Freeze`: 속도 0.5배
- `Haste`: 속도 1.25배
- `Stun`: 게이지 진행 0

즉 기본 speed 값은 그대로 두고, 상태이상이 그 위에 배율을 곱합니다.

## 액션 처리 순서

현재 액션 처리 순서:

1. `calc`
2. `damage`
3. `status apply`

- 먼저 액션 시작 시점 정보를 읽음
- 그 상태를 바탕으로 피해 계산
- 실제 피해 적용
- 마지막에 상태이상/후속 상태 효과 적용

중요한 규칙:

- 이번 액션에서 새로 적용된 상태는 같은 액션의 damage 계산에 되먹임되지 않음

## 스킬

- 기본 공격
- 4개 슬롯 스킬

적은 현재 기본 공격만 사용합니다.

## 전투 종료

- 플레이어 승리 시 최대 HP의 20% 회복
- 플레이어 패배 시 run 종료

## 로그

HUD는 전투의 요약 상태를 보여주고, 세부 이벤트 스트림은 DevTools `console.log`에서 확인합니다.

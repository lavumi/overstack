# Building Rules

이 문서는 시작 캐릭터 생성 규칙을 정리합니다.

## 시작 빌드의 구조

시작 빌드는 아래 세 요소로 구성됩니다.

- 시작 trait 1개
- 시작 스킬 1~4개
- 스탯 세트

즉, 시작 trait와 시작 스킬을 먼저 정하고 남은 예산으로 스탯을 맞추는 구조입니다.

## 시작 trait 규칙

- 정확히 1개 선택
- selectable trait 중에서만 선택
- trait cost는 시작 예산에 포함
- random은 weighted random으로 1개 선택
- manual은 직접 1개 선택

## 시작 스킬 규칙

- `Basic Attack`은 무료 기본 액션으로 항상 존재
- 그 외 시작 스킬은 1개 이상, 최대 4개까지 선택
- 각 스킬도 `cost`를 가짐
- 선택한 스킬 cost는 시작 예산에 포함
- 비어 있는 스킬 슬롯은 `Basic Attack`처럼 취급

## 시작 예산

현재 시작 예산:

- manual: `100`
- random: `120`

## 스탯 비용

현재 빌더는 각 스탯을 비용으로 환산합니다.

- 공격/방어/치명타는 비용을 가집니다.
- `speed`도 비용을 가집니다.
- `speed`는 배율이 아니라 절대값 스탯입니다.

현재 `speed`는 플레이어와 몬스터가 같은 절대값 스케일을 사용합니다.

즉:

- 플레이어 `speed`
- 몬스터 `spd`

는 같은 종류의 수치입니다.

상태이상 `Freeze`, `Haste`, `Stun`은 이 값 위에 배율 또는 정지를 적용합니다.

## Random build

1. weighted random으로 시작 trait 1개 선택
2. weighted random으로 시작 스킬들을 먼저 고른다
3. random 전용 예산 `120` 기준으로 남은 예산 계산
4. 남은 예산 안에서 실행 가능한 스탯 세트 생성

random도 예산 규칙을 무시하지 않습니다.

## Manual build

- 플레이어가 스탯을 직접 조정
- 시작 trait도 직접 선택
- 시작 스킬도 직접 선택
- 총 비용이 100을 넘을 수 없음

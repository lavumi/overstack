# Roadmap

현재 기준 다음 확장 후보를 정리합니다.

## 1. Reward system

- trait reward 선택
- cost 기반 reward sampling
- owned trait 제외 규칙 확장

## 2. Monster expansion

- enemy trait 활용 확대
- enemy skill 다양화
- 적 archetype 분화

## 3. Random builder quality

- trait-first는 이미 도입됨
- 다음 단계는 archetype 기반 stat allocation
- 랜덤 빌드 품질과 시너지 개선 필요
- 현재는 random budget 120 보너스를 사용 중

## 4. Content scale-out

- 새 스킬/trait/monster를 JSON 위주로 늘릴 수 있게 유지
- primitive 추가는 최소화

## 5. Frontend polish

- 전투 피드백 강화
- 더 정교한 HUD/애니메이션
- 필요 시 canvas 표현층 검토

## 6. Documentation

- 현재 새 문서 체계를 기준으로 계속 유지
- 시스템이 바뀔 때 gameplay/build/combat 문서를 먼저 갱신

## 7. Data / Rule cleanup

- player와 enemy speed 스케일 유지보수
- builder cost 공식 조정
- 랜덤 빌드와 수동 빌드 간 효율 차이 검토
